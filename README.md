# Proyecto Almacenes y Minería de Datos
Sitio desplegado:  https://erickluisjuarez.github.io/Proyecto_Almacenes_Datos/


Cada vez que realices cambios en algún archivo .qmd o agregues imágenes, debes compilar el sitio ejecutando en la raíz de la carpeta:
```bash
quarto render
```

Este comando actualizará automáticamente los archivos .html compilados dentro de la carpeta docs/.


Una vez compilado, publica tus avances en el repositorio remoto con los siguientes comandos:

```bash
git pull origin main
git add .
git commit -m "feat: Descripción de los cambios realizados"
git push origin main
```
